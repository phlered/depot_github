# Dépôt de documents — année 2026-2027

Documents transmis aux élèves : corrections d'exercices, devoirs surveillés,
annales, activités.

## Organisation

Un dossier par classe :

`1S/` · `2nde/` · `DNL1T/` · `DNL2/` · `TCO/` · `TS/`

Chaque dossier contient un fichier `.gitkeep` : c'est un marqueur qui permet à
Git de conserver un dossier vide. Il peut être supprimé dès qu'un document y
est déposé (ou laissé, il ne gêne pas).

## Accès aux documents

Chaque fichier déposé est publié automatiquement (GitHub Pages) à l'adresse :

```
https://phlered.github.io/depot_github/<classe>/<nom_du_fichier>
```

Exemple :

```
https://phlered.github.io/depot_github/1S/1-Second_degre/correction.pdf
```

Conseil : éviter les espaces et les accents dans les noms de fichiers pour
obtenir des liens courts et stables.
